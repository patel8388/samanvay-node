# Qualify a private no-value testnet

This is a future gate, not authorization to launch. The current application has no qualified P2P network, no independent volunteer operators, and no public testnet. Any rehearsal must use disposable tSAMV only and no real funds.

## Acceptance criteria

- Complete qualified-base, consensus, storage, security, and transport reviews first.
- Obtain explicit separate approval for the exact private test endpoints, operators, duration, and data handling before running a multi-machine rehearsal.
- Demonstrate at least four genuinely independent operators and two independently reachable peers, with a measured multi-day soak, recovery, and incident plan.
- Publish reproducible results and limitations. Multiple nodes controlled by one person do not count as operator independence.
- Keep public peer discovery, public ports, production services, token sale, or mainnet launch blocked until separate gates and approvals are met.
