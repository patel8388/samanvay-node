# Select and qualify the long-term Layer-1 base

Independently compare a maintained Bitcoin-derived client with a justified custom replacement before committing to a production architecture. The current Python account-chain is a research prototype and does not inherit Bitcoin's security.

## Acceptance criteria

- Compare protocol fit for PoW, 10 billion SAMV cap, staking rewards, mobile support, ecosystem, maintainers, licenses, dependencies, and migration cost.
- Pin an upstream release or document a reasoned replacement architecture; do not treat an unqualified prototype as the final public network.
- Review reproducible builds and supply-chain risks.
- Obtain independent protocol/security review before promoting the selected base to a testnet candidate.
- Record the decision and unresolved tradeoffs in the public repository; no production deployment is part of this task.
